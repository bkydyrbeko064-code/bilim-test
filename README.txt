BilimTest — готовый статический сайт для Cloudflare Pages.

Публикация через Direct Upload:
1. В Cloudflare откройте Workers & Pages.
2. Create application → Pages → Upload assets (или Direct Upload).
3. Имя проекта: bilimtest (если свободно).
4. Загрузите папку/архив с index.html и нажмите Deploy.

Важно: текущая версия содержит 4 демонстрационных теста по одному вопросу. Создание тестов, аккаунты, база данных и сохранение результатов пока не реализованы.
